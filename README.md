# 房貸方案比較工具

大亮泊建案 12 家銀行房貸方案比較工具。資料整理自各銀行對保 DM 原始掃描件，逐頁核對後修正資料誤植、補齊漏收方案。

## 功能

- 46 個銀行方案，利率／成數／年限／寬限期皆可直接編輯調整
- 成數預設為 DM 標示的最大可貸成數，可自行調整為銀行實際核准的成數
- 多方案勾選比較，含利率分布尺標、總利息長條圖
- 每個方案可展開逐期還款明細（分階段顯示 + 完整月繳表 CSV 下載）
- 可加入信貸／裝潢貸一併試算合併月付總額

## 本機開發

這是單一 HTML 檔案，用瀏覽器直接開啟 `index.html` 即可，不需要建置流程、不需要安裝任何套件。

## 資料驗證

`scripts/validate.js` 會檢查 `index.html` 內嵌的 JS 語法、bankData 資料完整性（筆數、必要欄位、id 是否重複、有無殘留的「同上」字樣等）。

本機執行：

```bash
node scripts/validate.js
```

## 自動部署

推送到 `main` 分支時，GitHub Actions 會先執行上述驗證，通過後才部署到 GitHub Pages。若驗證失敗，部署會被擋下，網站不會更新到有問題的版本。

第一次啟用需要到 repo 的 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**。

## 免責聲明

利率資料為特定建案與銀行團體議定的優惠專案，僅供試算參考，實際核貸利率、成數、費用以各銀行審核結果與最新公告為準。
